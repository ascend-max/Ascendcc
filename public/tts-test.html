Model, license and limits
  • Model: Kokoro-82M v1.0, ONNX build onnx-community/Kokoro-82M-v1.0-ONNX (82 million parameters).
  • Model license: Apache-2.0 — commercial use is permitted. Library kokoro-js 1.2.1 is also Apache-2.0.
  • Download: quantised model_quantized.onnx is 92,361,116 bytes (92.4 MB). One voice file is about 522 kB. Runtime, tokenizer and config files add a few more megabytes.
  • Runs on: ONNX Runtime Web (WebAssembly, single-threaded). Inference is CPU-bound: expect seconds per sentence, faster on desktop than on a low-end phone.
  • Nothing is saved to a server. Generated audio exists only in this tab until you download it.
  • Accuracy: pronunciation of numbers, names and currency can be wrong. Listen before publishing.
